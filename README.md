# StreamLighter — Virtual Ring Light Overlay (WPF)

Minimal WPF app that places a soft glowing frame around the screen to act as a virtual ring light.

Build & run

1. Requires .NET 7 SDK or later on Windows.
2. From project folder run:

```powershell
dotnet build
dotnet run --project .
```

Usage

- Use the small control window to toggle the overlay and adjust brightness.
- The overlay is click-through and covers all monitors.

Notes

- This is a minimal prototype. You can improve brushes, add color temperature, hotkeys, and system tray integration.
